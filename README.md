# 🛵 Line.Up - Phone & Lens Rental Service (Admin Web Application)

ระบบเว็บแอปพลิเคชันสำหรับผู้ดูแลระบบ (Admin) ของร้านเช่าโทรศัพท์มือถือและเลนส์เสริมสำหรับดูคอนเสิร์ตและอีเวนต์ **"Line.Up"**

---

## 🎨 การออกแบบและธีมสี (Design & Theme)
อ้างอิงตามโลโก้ร้าน Line.Up (น้องแมวซ้อนมอเตอร์ไซค์ส่งของ):
- **สีหลัก (Primary Color):** Mint Green (สีเขียวมิ้นต์ `#38c29e`)
- **สีรอง / ปุ่มเน้น (Accent Colors):** Pastel Pink (สีชมพูพาสเทล `#ff7599`) และ Bright Yellow (สีเหลืองสด `#facc15`)
- **สีตัวอักษร (Text Color):** Dark Slate / Charcoal Gray (`#1e293b`)
- **การแสดงผล:** Responsive 100% รองรับทั้งหน้าจอ Desktop, Tablet และ Smartphone (มี Mobile Drawer และแถบเมนูด้านล่าง)

---

## 🚀 ฟังก์ชันการใช้งานหลัก 5 ส่วน

### 1. หน้า Dashboard (ภาพรวมและปฏิทิน)
- **ปฏิทินแบบ Interactive:** สลับดูได้ทั้งแบบ **รายเดือน (Month View)** และ **รายปี (Year View)** พร้อมปุ่ม วันนี้, เดือนก่อนหน้า, เดือนถัดไป
- **ตารางงานคอนเสิร์ต:** แสดงแท็กคอนเสิร์ตในแต่ละวัน เช่น *Coldplay @ ราชมังคลาฯ, NCT DREAM @ อิมแพ็ค, IU @ ชาเลนเจอร์, Bruno Mars @ ราชมังคลาฯ*
- **แสดงอุปกรณ์ที่ถูกจอง:** แต่ละวันจะแสดงป้ายชื่อรุ่นเครื่อง/เลนส์ และชื่อเล่นลูกค้าที่จองคิวไว้
- **Day Details Modal:** คลิกที่วันใดๆ เพื่อดูสรุปรายละเอียดคิวทั้งหมดในวันนั้น พร้อมปุ่มกด `+ จองคิวเช่าสำหรับวันนี้` ทันที
- **การ์ดสรุป KPI:** แสดงจำนวนเครื่องที่กำลังถูกเช่าอยู่, มือถือที่ว่าง, เลนส์ที่ว่าง, และยอดรายได้เดือนนี้

### 2. หน้าคลังอุปกรณ์ (Equipment Inventory)
- **แยกตารางอิสระ:** สลับแถบระหว่าง **"📱 โทรศัพท์มือถือ (Smartphones)"** และ **"📷 เลนส์เสริม (Lenses)"**
- **คอลัมน์ข้อมูลครบถ้วน:**
  - รุ่น (Model) และอุปกรณ์ที่ให้ไปด้วย (สายคล้องคอ, เคส, ฟิล์ม)
  - รหัสเครื่อง (ID เช่น `PH-01`, `LN-01`) และเลขซีเรียล
  - อีเมลประจำเครื่อง (User Mail / Apple ID) พร้อมปุ่มคัดลอกใน 1 คลิก
  - รหัสผ่าน (Password) พร้อมปุ่มรูปดวงตาสำหรับกดแสดง/ซ่อนรหัส และปุ่มคัดลอก
  - สถานะอุปกรณ์ (Status): **ว่าง (Available)**, **ถูกจอง (Booked)**, **ส่งซ่อม (Maintenance)** พร้อม Dropdown เปลี่ยนสถานะด่วน
- **สิทธิ์ Admin CRUD:** เพิ่มอุปกรณ์ใหม่, แก้ไขข้อมูล, ลบข้อมูล, ค้นหา (Search) และกรองตามสถานะ

### 3. หน้าจัดการการจอง (Booking Management)
- **ฟอร์มรับจองคิว:** บันทึกชื่อเล่นลูกค้า, ชื่อจริง, เบอร์โทร, Line ID, เลือกงานคอนเสิร์ต, เลือกระยะเวลาเช่า
- **ตัวเลือกอุปกรณ์:** เลือกได้ทั้ง *เฉพาะเครื่อง (Phone Only)*, *เฉพาะเลนส์ (Lens Only)*, หรือ *แบบครบเซ็ต (Full Set)* พร้อมเลือกเครื่องที่ว่างจากคลัง
- **ระบบราคาแบบไดนามิก (Dynamic Pricing):**
  - แอดมินสามารถเปิดเมนู `⚙️ จัดการราคาตามอีเวนต์` เพื่อกำหนดเรทราคาค่าเช่าของแต่ละคอนเสิร์ตล่วงหน้า (ราคาแต่ละงานไม่เท่ากัน)
  - เมื่อเลือกลักษณะการเช่า ระบบจะคำนวณราคารวมและเงินมัดจำให้อัตโนมัติทันที
- **ข้อมูลการจัดส่ง:**
  - ระบุวิธีรับ-คืนเครื่อง: *🏟️ นัดรับหน้าคอนเสิร์ต, 🛵 แมสเซนเจอร์ (Grab/Lalamove), 🏬 รับที่หน้าร้าน* พร้อมระบุจุดนัดหมาย
  - อัปเดตสถานะการส่งมอบ: *รอส่งมอบ (Pending), ส่งมอบแล้ว (Delivered), รับคืนแล้ว (Returned), ยกเลิก (Cancelled)*
  - ระบบจะซิงค์สถานะความว่างของอุปกรณ์ในคลังให้อัตโนมัติเมื่อมีการส่งมอบหรือรับคืน
- **ระบบตรวจสภาพอุปกรณ์ (Condition Inspection):**
  - ปุ่ม `📸 ตรวจสภาพ` ในแต่ละคิว
  - บันทึกสภาพอุปกรณ์ก่อนส่งมอบ (Before Delivery): อัปโหลดรูปภาพ, ระดับแบตเตอรี่, ผู้ตรวจสอบ, บันทึกสภาพเดิม
  - บันทึกสภาพอุปกรณ์หลังรับคืน (After Return): อัปโหลดรูปภาพหลังใช้งาน, บันทึกตำหนิ (Defect Remarks), คำนวณค่าปรับกรณีมีรอยชำรุด

### 4. หน้าจัดการลูกค้าและสัญญาเช่า (Customer & Documents)
- **ฐานข้อมูลลูกค้า:** บันทึกชื่อเล่น, ชื่อจริง, เบอร์โทร, Line ID, Social Media, เลขบัตรประชาชน
- **ป้ายกำกับแจ้งเตือน (Customer Tags):**
  - ⭐ **VIP:** ลูกค้าประจำ เช่าบ่อย ดูแลเครื่องดีมาก คืนตรงเวลา
  - 🚫 **Blacklist:** บุคคลเฝ้าระวัง/มีประวัติโกงหรือทำของพัง (ระบบเตือนห้ามให้เช่า)
  - ⚠️ **Caution:** ลูกค้าเฝ้าระวัง เคยส่งคืนเลท
  - 🟢 **Regular:** ลูกค้าทั่วไป
- **ประวัติการเช่าย้อนหลัง (Rental History Viewer):** คลิกดูลูกค้าแต่ละคนเพื่อดูว่าเคยเช่าเครื่องไหน ไปงานคอนเสิร์ตอะไร และยอดเช่าสะสมเท่าไหร่
- **ระบบพิมพ์สัญญาเช่า (Printable Rental Agreement):**
  - สร้างเอกสารสัญญาเช่ามาตรฐานพร้อมโลโก้ Line.Up, รายละเอียดผู้เช่า, รายการอุปกรณ์, เงินมัดจำ, เงื่อนไขการดูแล และช่องลงชื่อ
  - รองรับการสั่งพิมพ์ (Print) หรือบันทึกเป็น PDF ขนาด A4 ได้ทันที

### 5. หน้าสรุปยอดเงิน (Revenue Summary)
- **สรุปภาพรวมการเงิน:** รายได้รวมทั้งหมด, รายได้เฉลี่ยต่อออเดอร์ (AOV), จำนวนการจองทั้งหมด, เงินประกันมัดจำคงค้าง
- **กราฟสรุปยอดขาย (Chart.js):**
  - กราฟแท่งแสดงแนวโน้มการเติบโตของรายได้ (Revenue Trend)
  - กราฟโดนัทแสดงสัดส่วนรายได้ (Revenue Share)
- **แบ่งสัดส่วนรายได้ชัดเจน 3 กลุ่ม:**
  - 📱 โทรศัพท์มือถือ (Phone Only)
  - 📷 เลนส์เสริม (Lens Only)
  - ✨ แบบครบเซ็ต (Full Set: มือถือ + เลนส์)
  - แสดงทั้งยอดเงินบาท และเปอร์เซ็นต์ % สัดส่วน
- **ตารางจัดอันดับคอนเสิร์ตทำเงินสูงสุด (Top Events by Revenue):** สรุปยอดรายได้แยกตามแต่งานคอนเสิร์ต
- **ส่งออกข้อมูล (Export CSV):** ดาวน์โหลดรายงานการเช่าและการเงินเป็นไฟล์ CSV สำหรับงานบัญชี

## 💻 วิธีการเปิดใช้งาน (How to Run)

### วิธีที่ 1: เปิดไฟล์ตรงผ่านเว็บเบราว์เซอร์ (ง่ายที่สุด)
ดับเบิลคลิกที่ไฟล์ `index.html` เพื่อเปิดใช้งานใน Google Chrome, Microsoft Edge, หรือเบราว์เซอร์ใดๆ ได้ทันทีโดยไม่ต้องติดตั้งโปรแกรมเพิ่ม

### วิธีที่ 2: รันผ่าน Local Server (PowerShell)
เปิด PowerShell ในโฟลเดอร์นี้ แล้วพิมพ์คำสั่ง:
```powershell
.\server.ps1
```
จากนั้นเปิดเบราว์เซอร์ไปที่: `http://localhost:3000`

---

## 💾 ระบบบันทึกข้อมูล (Data Storage)
ระบบใช้ **LocalStorage** ในเครื่องของผู้ใช้ ทำให้สามารถทดสอบ เพิ่ม แก้ไข ลบ ข้อมูลได้จริงแบบ Persistent และมีปุ่ม `🔄 รีเซ็ตข้อมูลตัวอย่าง (Demo Data)` ที่แถบเมนู เพื่อให้สามารถย้อนกลับมาดูข้อมูลตัวอย่างที่สมบูรณ์ได้ทุกเมื่อ
